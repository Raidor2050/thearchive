# V1.2 // THE ARCHIVE — THREE-TIER IMPLEMENTATION

Status: APPROVED · Implemented in this folder (`V1.2`). Rollback: pristine copy lives in `Backup1` (same parent folder).

## 1. Vision
A bottom-left button (revealed after the archive is fully lived through) unlocks a second experience tier, SIGNAL — the same stories rewritten as "THE RERUN" with updated graphics, plus a new set of story-themed games. Completing SIGNAL unlocks VAULT, a visually stunning 3D version of the archive. The original ARCHIVE tier must remain pixel-identical to V1.1.

## 3. State model & migration
- Same localStorage key `raiyan-ruby-ui-v11`. New `schemaVersion:2`. In-place migration via pure `migrateFromV11(raw,v)`:
  - v1 → v2: backfill `contactReached = playedGames.length >= 6` and (if so) `signalUnlocked = true`; set `schemaVersion:2`.
  - Per-key sanitizers: `signalFlags` keeps only the 4 known ids with `true`; arrays re-created; `tier` clamped to archive|signal|vault; numeric clamps; `contactReached` backfilled from `signalUnlocked` when missing.
- New keys: `schemaVersion, tier, variant, signalIndex, signalHistory, signalStarted, signalReachedFinal, signalFlags{altRouteRelay,altCableTriage,altSignalChain,altAsyncBatch}, signalComplete, signalXp, signalFound, signalEnterCount, signalAchievementsUnlocked, signalAchievements, signalUnlocked, contactReached, vaultUnlocked, vaultVisited, vaultProgress, vaultQuality`. Existing 17 V1.1 keys untouched.
- Latch rules (never lost after earned): `signalUnlocked` only when the user reaches the CONTACT popup — `latchContactReached()` runs at the top of `openContact()`, so it fires from the end-of-story contact choice, the bottom contact icon button, or the `C` hotkey. Playing all 6 archive games no longer unlocks it (only the `allGames` achievement). `signalComplete = latch || (4 flags && signalReachedFinal)`; `vaultUnlocked` latches when signalComplete.
- `openHome()` resets tier→archive, resets signal replay progress (index/history/flags/started/reachedFinal/xp/found/enterCount) but NEVER clears signalUnlocked/vaultUnlocked/signalComplete/signalAchievements.

## 4. Tier system
- `setTier(t)` guards: signal needs signalUnlocked, vault needs vaultUnlocked, blocked while a game is open or modal is open.
- Parallel story positions: `index/history` (archive), `signalIndex/signalHistory` (signal). `current()/goto()/back()/renderScene()` are tier-aware. Vault hides the dialogue entirely (3D).
- `#tierBtn` fixed bottom-left (`calc(14px + env(safe-area-inset-left/bottom))`), z 6 (z 32 when vault active), min 56px, keyboard shortcuts `S`/`V` (added in tier.js, not script.js).
- Label matrix: archive → hidden until signalUnlocked; then `SIGNAL · n/4` or `VAULT · READY` (pulse) when vault ready. signal → `ARCHIVE` or `VAULT · READY`. vault → `ARCHIVE`.
- Transition FX `#tierVeil`: expanding `clip-path: circle()` from the button rect; bg = target tier color (vault uses white flash). Reduced-motion: instant switch.
- FOUC: tiny inline `<head>` script adds `tier-ready`/`vault-ready` classes before stylesheets paint (tier-ready when saved `signalUnlocked` OR `contactReached`; NOT from playedGames alone).

## 5. SIGNAL visual spec (tokens)
`--bg:#050a1a; --accent-p:#a855f7; --accent-c:#22d3ee; --fg:#e2e8f0;` glass `rgba(255,255,255,.05)` + blur, radius 8/12/16, spring `cubic-bezier(.34,1.56,.64,1)`. All 17 hardcoded hex literals in styles.css become CSS vars; `body[data-tier="signal"]` redefines the token block (one override section, `[data-tier="signal"]`). Archive tier = default tokens, visually identical to V1.1. `games.css` untouched.

## 6. Story variant
- `story-data.js`: `SIGNAL_SCENES` (~30 scenes, "THE RERUN"), dynamic `sigGate` (same pattern as `storyGate`, gating the 4 alt games), `signalFinal` scene latches `signalReachedFinal` → `vaultUnlocked`. Signal secrets numbered 100+ to avoid colliding with archive secrets. `ALT_GATE_LINES`, `ALT_ORDER`, `remainingSignalGames()`, `SIGNAL_ACHIEVEMENTS`.

## 7. Four new SIGNAL games (games-alt.js + games-alt.css)
1. `altRouteRelay` — SIGNAL RELAY: BFS path over a walled grid; tap the correct next relay before the packet arrives (DOM grid, seeded-testable).
2. `altCableTriage` — CABLE TRIAGE: rule table + junction box; cut the requested cable; wrong cut costs a life.
3. `altSignalChain` — SIGNAL CHAIN: Simon-style chain of the 6 archive chapters; replay the growing sequence.
4. `altAsyncBatch` — ASYNC BATCH: typing game against an overflow queue.
- Shared `state.leaderboard` with `alt_*` keys. `startGame()` shim routes alt ids to `startSignalGame()`. Results flow unchanged; `markSignalGamePlayed()` latches flags, XP, achievements (`SIGNAL_ACHIEVEMENTS`, incl. `altAllGames` TRANSMISSION COMPLETE). ShowResults/openLeaderboard fall back to GAMES_ALT for titles.

## 8. VAULT 3D (tier3d.js + tier-loader.js + tier3d.css)
- Helix of ~29 chapter panels (canvas textures, Determination Mono) + 6000-vertex Points starfield, FogExp2, MeshBasicMaterial, additive glow sprites, damp-lerp camera (drag + wheel zoom), raycast click → chapters/rooms/notes. Hooks: `VAULT3D.onChapter/onRoom/onEnter/onExit/onNote`.
- Loader ladder: reduced-motion poster → WebGL detect → (http only) importmap module path → vendored three.js r160 UMD (`assets/vendor/three@0.160.1.min.js`, MIT) with jsDelivr UMD fallback → CSS-3D fallback.
- Z-map: canvas 30, experience 31, lb-float 34, modal 35, toast 40. `body.vault-active` drives layout.
- Inspired by Remotion-style visuals (Repos: mrdoob/three.js, juliangarnier/3D-CSS-Solar-System, mtzngn/canvasConstellation, bramus/view-transitions-demos, JUNGHERZ/GlassKit — all MIT/Unlicense/Apache; unlicensed repos are INSPIRE-only).
